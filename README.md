# 通用智能刷题器 (Universal Quiz App)

基于 `shukong-quiz` 深度重构与升级的**全功能通用刷题平台**。支持多题库管理与一键无缝切换、多样化试题导入、智能文本容错解析、苹果毛玻璃 (Liquid Glassmorphism) 现代化 UI、填空式题干动态嵌词、全真模拟考试、错题重练与答题卡等完整学习链路。

---

## 🌟 核心特性

1. **多题库管理与独立存储**：
   - 支持内置示范题库与无限个用户自定义导入题库，完全解耦独立运行。
   - 题库间练习进度、错题本、收藏夹、模拟考试历史各自独立，互不污染。
   - 支持题库导出为标准 JSON 格式进行分享与备份。

2. **超简易题库导入体系与智能容错**：
   - **简易文本粘贴**：极高容错率，直接从 Word、TXT、微信笔记复制粘贴。
   - **智能容错与排版诊断**：自动清洗水印/页码噪音、单行多选项拆分、残缺选项自动补齐、缺失答案安全兜底。
   - **就地交互纠错**：导入预览卡片支持直接轻点选项修正答案，即时生效。
   - **一键模板体验**：内置「📋 填入范例模板」，一键加载示范题目。
   - **实时统计与卡片预览**：即时统计题目数、单选/判断题型、分类分布，实时渲染试题卡片与填空效果。
   - **本地文件与 JSON 导入**：支持一键拖拽上传 `.txt`、`.csv`、`.json`、`.md` 文件。

3. **智能题干填空与动态答题**：
   - 自动识别题干括号 `（ ）`，支持题干自带答案字母提取（如 `（A）`）。
   - **做题模式**：未作答时呈现浅蓝微光虚线胶囊留白 `（    ）`；作答后动态点亮为翡翠绿胶囊 `（ A · 选项内容 ）`。
   - **背题模式**：直接将标准答案和内容置入题干，读题通顺流畅，强化记忆。
   - **考试模式**：实时随考生选中的选项嵌入题干，交卷前不泄露对错。

4. **沉浸式交互与全真模拟**：
   - 顺序基础练习（自动记忆上次位置）、随机练习、分类专项练习。
   - 全真模拟考试：标准卷与自定义卷，倒计时限时交卷、及格全屏礼花彩带（Confetti Rain）。
   - 答题卡抽屉：题号色彩状态指示，快速跳转，答题记录独立清理。
   - iOS 18 风格毛玻璃设计，无缝支持浅色、深色（OLED护眼纯黑）与跟随系统主题。

## 📖 题库导入格式快速参考

### 单选题简易格式
```text
1. 道德是通过（ ）对一个人的品行发生极大的作用。
A. 社会舆论
B. 国家强制执行
C. 个人的影响
D. 国家政策
答案：A
分类：职业道德
解析：道德主要靠社会舆论、传统习俗和内心信念起作用。
```

### 判断题简易格式
```text
2. Python 是一种解释型高级编程语言。（ ）
答案：正确
分类：编程技术
解析：Python通过解释器逐行翻译执行字节码。
```

## 🚀 启动与测试方法

### 1. 本地启动服务
```bash
python server.py
```
默认监听并在浏览器访问：`http://127.0.0.1:8088`

### 2. 自动化端到端测试
```bash
python test_quiz_universal.py
```
包含题库切换、简易文本一键导入、题干括号渲染、做题/背题切换、答题卡操作的完整自动化测试套件。

## 📱 Android 安装包 (APK)

本项目提供独立的 Android 原生壳封装，内置离线资源、离线题库存储、振动触觉反馈以及原生返回键栈导航。

- **直接下载安装**：前往 [GitHub Releases](https://github.com/POKMJN/universal-quiz/releases) 或直接下载仓库根目录中的 [`universal-quiz-v1.0.apk`](file:///C:/Users/22816/.gemini/antigravity/scratch/universal-quiz/universal-quiz-v1.0.apk)。
- **源码工程**：位于 `android/` 目录，可使用 Android Studio 或 Gradle 命令行直接编译：
  ```bash
  cd android
  ./gradlew assembleRelease
  ```
