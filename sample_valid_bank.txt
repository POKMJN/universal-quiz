题库：计算机网络与网络安全全真模拟题库

1. 在 TCP/IP 参考模型中，负责提供端到端可靠数据传输服务的核心协议是（ ）。
A. IP 协议
B. TCP 协议
C. UDP 协议
D. ICMP 协议
答案：B
分类：网络协议
解析：TCP（传输控制协议）是面向连接的、可靠的传输层协议，通过三次握手、确认重传和滑动窗口实现可靠传输。

2. 现代公钥密码学体系中，RSA 算法的数学安全性主要依赖于以下哪个数学难题？（ ）
A. 离散对数问题
B. 大整数质因数分解困难性
C. 椭圆曲线点乘运算
D. 快速傅里叶变换
答案：B
分类：信息安全
解析：RSA 加密算法基于数论中的欧拉定理和大素数乘积分解极度困难的特性构建。

3. HTTP 协议在默认情况下所使用的传输层协议和标准知名端口号是（ ）。
A. UDP 协议，80 端口
B. TCP 协议，80 端口
C. TCP 协议，443 端口
D. UDP 协议，8080 端口
答案：B
分类：Web技术
解析：普通未加密的 HTTP 协议建立在 TCP 之上，标准服务端口为 80；而加密的 HTTPS 则使用 443 端口。

4. 计算机在执行程序时，CPU 能够直接高速寻址访问的内部存储器是（ ）。
A. 固态硬盘（SSD）
B. 随机存取存储器（RAM）
C. 机械硬盘（HDD）
D. 磁带机
答案：B
分类：体系结构
解析：CPU 只能直接寻址访问内部主存（RAM 和 ROM）及各级 Cache，外存需要先调入内存后方可执行。

5. 在对称加密算法（如 AES）中，加密密钥与解密密钥是完全相同或容易相互推导的。
答案：正确
分类：加密算法
解析：对称加密的核心特征就是加解密双方共享同一把安全密钥，算法效率极高但密钥分发要求严苛。

6. 域名系统（DNS）在进行大多数客户端主机名解析查询时，默认采用的是 TCP 连接。
答案：错误
分类：传输层
解析：普通 DNS 主机名查询为了降低握手开销和加快响应，默认采用无连接的 UDP 53 端口；仅在区域传送（Zone Transfer）或响应超长时才使用 TCP。
